## 旧版检查更新后仍未升级

v1.7.40 和早期 v1.7.41 的下载器存在文件占用问题。请使用 [一键修复更新工具（Windows x64）](https://github.com/yoursheng533-debug/ForeignTradeCrm-Releases/releases/download/v1.7.42/ForeignTradeCrm-Update-Repair-win-x64-v1.7.42-07e5091ba0a2.zip)。

1. 下载 ZIP，完整解压到一个新文件夹，不要覆盖原 CRM 文件夹。
2. 使用原 Windows 用户，保存并关闭 CRM，双击“一键修复更新.bat”。
3. 确认自动找到的原安装目录；未找到或有多个目录时选择平时使用、含 app 和 data 的原文件夹，点击“一键修复更新”。
4. 完成后从原桌面入口启动。邮件、数据、附件、邮箱凭据、SSH/Tailscale 连接配置和自定义模板均保留，旧程序自动备份。

工具自带完整新程序及运行环境，使用时不依赖旧下载器或额外下载，无需手动替换文件夹。修复后后续新版本恢复软件内“检查更新”。若勾选自动启动，请选择原来的连接方式。
